# npm依存関係の監査

2026-11-18 JSTに `npm audit` と `npm audit --omit=dev` を実行。件数はnpmが報告した影響パッケージ数で、同じ原因で影響を受ける上位パッケージも含まれる。

| 対象 | 更新前 | 更新後 |
| --- | --- | --- |
| 開発用を含むロック | 高14・中15・重大0 | 高14・中13・重大0 |
| npm本番用依存 | 0件 | 0件 |

配信用ビルドは許可リストの静的資産だけを含む。npmの直接依存 `firebase`、`firebase-tools`、`@firebase/rules-unit-testing` は開発用。配信HTMLのFirebase SDKはCDN上の11.10.0をSRI付きで参照しているため、上表のnpm監査の対象外。BotのPython依存は別系列。

| 原因パッケージ | 解決した版・経路 | 対応と判断 |
| --- | --- | --- |
| `@hono/node-server` | 2.1.5 → 2.1.9。開発CLIのMCP SDK経由。 | 親のsemver範囲に収まるパッチで、中2件のアドバイザリを解消。 |
| `hono` | 4.13.13 → 4.13.19。同SDK経由。 | 同じメジャーのパッチで、中5件のアドバイザリを解消。 |
| `@grpc/grpc-js` | 影響版1.9.16は開発用Firestore SDK配下。 | 修正は1.13.6以降。現行Firestoreと調査時点の最新版が `~1.9.0` を要求。強制上書きは通信・エミュレータへの影響があるため、親の対応版で検証する。 |
| `@opentelemetry/core` | 影響版1.30.1は開発CLI配下のCloud Pub/Sub経由。 | 修正は2.8.0以降。親は1系指定。メジャー差を含むため親パッケージの更新を待って検証する。 |
| `glob` | 影響版10.5.0はCLIとアーカイブ系で共有。 | 修正は14.0.2以降。直接・間接依存が10系を指定しているため、複数の親の対応が必要。 |
| `minimatch` | 影響版9.0.9は `glob` 配下。CLIには影響範囲外の旧版も存在。 | 修正は11.0.1以降。パターン処理の互換性を含め、親の更新と合わせて検証する。 |
| `picomatch` | 影響版2.3.2・4.0.7はファイル監視・探索系。 | 調査時点で最新4.0.7も影響範囲。修正版と親の対応を確認する。 |
| `uuid` | 影響版9.0.1は開発CLI配下の `gaxios` 経由。 | 修正は11.1.1以降。親のメジャー制約とAPI互換性を確認してから更新する。 |

Honoの2つだけをロックで更新し、アプリ依存宣言やCDN参照のバージョンは同じ。確認には `npm ci`、Web試験、デモFirebaseのRulesとUI試験を使う。今後の優先は、高14件に影響する `@grpc/grpc-js` と `picomatch` を親パッケージの対応版で再評価すること。
