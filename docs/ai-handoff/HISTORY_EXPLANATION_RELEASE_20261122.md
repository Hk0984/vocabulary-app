# 世界史解説統合の本番反映（2026-11-22 JST）

ユーザーから、109問の要確認解説を双方の要素を落とさずに統合し、本番単語帳アプリへ反映するよう明示的な依頼を受けた。

## 変更範囲
- 世界史一問一答1,536問に追加されている解説の表示のみ。
- 既存13列の公開・管理用Google Sheets、問題ID、正解、地域分類、Firestore履歴の更新なし。
- 要確認109問は、基礎を従来解説にした95問、選択肢別解説にした13問、両方を再構成した1問に分類して個別統合。
- 原文と選択肢別解説が一致した場合にのみ確定統合文を利用。それ以外はビルドを失敗させる。
- 一般の1,536問も文章の包含・重複を整理して1つの欄へ表示する。

## 公開ルート
- このファイルのmain取り込みで `.github/workflows/history-explanations-20261122.yml` の一度きりのパス限定公開フローを開始する。
- 全npm回帰・1,536問照合・109問レビュー文照合・現行Pages設定照合・rebuild_v1ビルドが成功した場合のみGitHub Pagesに公開する。
- Actionsが失敗した場合、既存Pagesの配信は置換しない。
- 本件のリリース以外に自動公開を広げない。通常の手動公開ワークフロー `web-release.yml` は変更しない。
- 公開後に1,551問中1,536問への拡張データの一致と実際の表示を確認する。

## 戻し方
公開後に不具合が生じた場合は、このPRをrevertして、既存の手動承認ワークフローから直前の承認済み本番ビルドを再発行する。公開用Sheets・履歴には変更を加えていない。
