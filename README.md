# 単語学習アプリ

**英単語・古文などの暗記学習と、世界史の4択問題を解くためのWebアプリです。**  
問題を解くだけでなく、間違えた単語の復習、正答率の確認、世界史の時代の流れを学ぶ問題にも対応しています。スマートフォン・PCのブラウザから利用できます。

**[アプリを開く（GitHub Pages）](https://hk0984.github.io/vocabulary-app/)**

> この説明はリポジトリの `main` ブランチの実装を基にしています。GitHub上の更新内容と、実際に公開されているWeb版の反映タイミングは異なる場合があります。

## まずは使ってみる

1. 上のリンクからアプリを開きます。
2. **「ログインする」**でメールアドレスとパスワードを使ってログイン・新規登録するか、**「ログインせず試してみる」**を選びます。
3. **「学習」**からジャンルを選び、学習モード・出題形式・問題数などを設定します。
4. **「学習開始」**を押して問題に答えます。回答後は正誤を確認し、次の問題へ進みます。
5. 終了後は正答率を確認できます。間違えた問題があれば、その回の誤答を復習できます。

**学習履歴を残したい場合はログインしてください。** 匿名で試す場合、回答履歴は保存されません。ログイン済みでも、通信障害などで保存に失敗した回答は自動で再送されません。画面に保存失敗の案内が出た場合は注意してください。

## 学べる内容

| メニュー・学習形式 | できること |
| --- | --- |
| **通常の単語・用語学習** | Google Sheetsのジャンルに登録された表面・裏面のデータから、選択式の問題を出題します。英単語・古文など、登録されている教材に共通の仕組みです。 |
| **世界史一問一答** | 世界史の4択問題を解きます。時代・世紀・地域で問題を絞り込み、解答後に解説を確認できます。対応する問題には選択肢別の解説や地図も表示します。 |
| **世界史の流れ** | 「同じ時代の出来事は？」「古い順に並べると？」といった問題のほか、複数の空欄を埋める問題で歴史のつながりを学びます。 |

実際に表示されるジャンルや問題数は、公開されている教材データと選択条件によって変わります。

## 通常学習の設定

「学習」でジャンルを選ぶと、学習条件を設定できます。

### 学習モード

| モード | 出題するもの |
| --- | --- |
| **通常学習** | 選択した範囲内の単語・用語 |
| **苦手単語** | 過去の回答の**誤答率が41%以上**の単語 |
| **未学習単語** | まだ回答記録のない単語 |
| **間違えた単語** | 過去に1回でも間違えた単語 |

苦手・未学習・間違えた単語の判定には、利用中のアカウントの学習履歴を使います。履歴を読み込めないときは、履歴を使うモードを開始できない場合があります。

### 出題形式と問題数

- **表面 → 裏面／裏面 → 表面**：たとえば英語から日本語、日本語から英語のように、問題を出す向きを切り替えます。
- **意味の通常版／高難易度版**：複数の意味がある語では、高難易度版で表示する意味を絞って出題できます。
- **全範囲／ID指定**：IDがある通常教材は、開始IDと終了IDで範囲を指定できます。
- **問題数**：10問・20問・50問・無制限などから選びます。ジャンルによって選べる数は異なります。

問題は基本的に選択式です。紛らわしい誤答候補を選びやすくするため、教材の属性ラベルやレビュー済み候補辞書を利用します。適切な誤答候補が不足する場合、**2～3択に減らす、またはその問題をスキップする**ことがあります。無理に不適切な選択肢を足して4択にはしません。

## 世界史一問一答の使い方

1. トップの**「世界史一問一答を学ぶ」**、または上部の**「歴史」**から学習設定を開きます。
2. 必要に応じて**時代・世紀・地域**を選んで絞り込み、出題順（ランダム／登録順）などを設定します。
3. 学習を始めて、4つの選択肢から回答します。
4. 解答後に正解と解説を確認し、次の問題へ進みます。

問題によっては、正解・選んだ誤答それぞれの説明や、国・歴史上の地点を示す地図を表示します。**すべての問題に地図や選択肢別解説があるわけではありません。** 地図は問題の種類に応じて現在の国境または確認済みの地点を使い、歴史上の領域を完全に再現するものではありません。

## 世界史の流れの使い方

トップの**「世界史の流れを学ぶ」**から開き、出題形式を選択します。

- **同時代判定**：複数の出来事の中から、同じ時代に当てはまるものを選びます。
- **年代順並び替え**：出来事を古い順に並び替えます。
- **複数空欄補充**：歴史の説明文にある複数の空欄を、選択または入力で埋めます。

時代・世紀・地域、出題順（ランダム／登録順）、問題数（10・20・30・すべて）を指定できます。回答後には正解と解説が表示され、終了後は再挑戦もできます。

> **重要：**「世界史の流れ」の成績は、その学習セッション内のみ表示されます。**ログインしていても学習履歴には保存されません。**

## 学習状況を確認する

ログイン後、上部の**「学習状況」**からジャンルを選ぶと、回答記録を確認できます。

- 全体正答率、総回答数、現在・最高の連続正解
- 誤答率別（0～20%、21～40%など）と未学習の単語数
- 単語ごとの回答回数・正答率・誤答率と、苦手順などの並び替え

**「このジャンルの学習状況をリセット」**は、そのジャンルに保存された履歴を削除する操作です。確認画面をよく読んでから実行してください。画面を閉じたりログアウトしたりするだけでは、保存済みの履歴は削除されません。

## アカウントとデータの保存

- **メールアドレス・パスワードで登録／ログイン**：Firebase Authenticationを利用します。ログイン後の通常学習・世界史一問一答の回答履歴は、Firestoreにアカウント別で保存されます。
- **ログインせずに試す**：匿名認証で問題を体験できますが、回答履歴は保存しません。
- **匿名利用から登録**：アカウント登録画面からメールアドレス・パスワードを設定できます。ただし、匿名利用中の過去の回答記録がさかのぼって保存されるわけではありません。

公開ページはインターネット上からアクセスできます。ログイン機能は**学習履歴の保存先を区別するため**のもので、サイト全体を非公開にする仕組みではありません。

## スマートフォン・PWAで使う

本アプリはスマートフォン向けの表示と、ホーム画面から起動できる**PWA（Webアプリ）**に対応しています。

- **iPhone（Safari）**：アプリを開き、共有メニューから「ホーム画面に追加」を選びます。
- **その他の対応ブラウザ**：インストール／ホーム画面追加のメニューが表示される場合は、そこから追加できます。

更新がある場合は、学習途中に強制的に画面を切り替えず、アプリ内で案内します。**学習を終えた後に、開いているタブとホーム画面アプリを閉じ、開き直してください。**

画面や一部ファイルがキャッシュされても、**問題データの取得やログイン・履歴の同期には通信が必要**です。完全オフラインでの学習・同期を保証するものではありません。

## 問題を追加・作成したい場合

通常教材は、**Google Sheetsに登録された問題データ**をアプリが読み込む方式です。最低限の基本項目は次のとおりです。

| ID | 表面 | 裏面 |
| --- | --- | --- |
| 1 | improve | 改善する |
| 2 | maintain | 維持する |

- 教材の内容に合わせて**表面・裏面**を入れ替えて利用できます。
- 必要に応じて、誤答候補の分類に使う `front_tags`・`back_tags` を追加できます。既存の問題IDは変更しないでください。
- 授業プリントの画像やPDFをChatGPTなどで文字起こしし、CSV形式に整理してから、**管理者が内容を確認して教材へ反映**することもできます。

**注意：アプリの学習画面に任意のCSVを直接アップロードして登録する機能はありません。** CSVの作成・確認と、公開Google Sheetsや管理Botへの反映は別の作業です。世界史一問一答と世界史の流れは通常教材とは異なるデータ形式・承認手順を使います。

教材を作成・管理する方向けの詳しい仕様は、[通常教材の属性ラベル・世界史の流れ](docs/STUDY_DATA_SPEC.md)、[世界史一問一答の作問仕様](docs/HISTORY_QUIZ_AUTHORING.md)、[Discord Botによる世界史教材管理](bot/README.md)を参照してください。管理用の非公開データを公開シートやGitHubへそのまま置かないでください。

## 困ったときは

| 状況 | 確認すること |
| --- | --- |
| ジャンルや問題が読み込めない | インターネット接続を確認し、アプリを開き直してください。教材の公開データ取得に失敗している可能性があります。 |
| 苦手単語・未学習単語を選べない | ログイン状態と履歴の読み込み状況を確認し、表示される場合は**「履歴を再読み込み」**を押してください。 |
| 問題が4択にならない | 選択肢の候補が足りないと、2～3択やスキップになる場合があります。 |
| 回答の成績が反映されない | 保存失敗の表示がないか確認してください。未保存回答は自動再送されません。 |
| 世界史の地図が表示されない | その問題に地図情報が設定されていない可能性があります。 |
| 更新後の画面が古い | 学習終了後に、関連するタブとホーム画面アプリをすべて閉じてから開き直してください。 |

## 開発・運用者向け

このリポジトリには、Webアプリ、公開教材の読み取り処理、Firebase連携、世界史教材を管理するDiscord Bot、テストが含まれます。開発環境では**Node.js 24.12以上**が必要です。

基本的なコード・Webビルド検証：

```sh
npm ci
npm test
npm run build:web -- --out dist/readme-review
```

BotのPythonテストやFirestore Rulesテストは別途実行します。**本番の認証情報をローカルテストやCodex Cloudに渡さないでください。** デプロイ・本番教材の変更には別の承認が必要です。
